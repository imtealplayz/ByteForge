MAP VOCABULARY

Main / Link / Mid / Site

Main is a primary lane toward a site. Link connects areas. Mid is a central control space. Site is where the Spike can be planted.

Default

A common plant/setup location. The exact default changes by map and strategy.

Choke

A constrained route where utility, crossfires and timing can be concentrated.

MAP STUDY LOOP

  1. Memorize callouts and major lanes.
  2. Learn defender rotations.
  3. Identify attack-side choke points.
  4. Study unique map mechanics.
  5. Then add lineups and set plays.
