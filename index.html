REFERENCE / BATTLEFIELDS

Maps

Use source artwork for context and the actual source layout image for routes, sites and callouts.

MAP VOCABULARY

Main / Link / Mid / Site

Main usually means a primary lane into or toward a site. Link connects areas. Mid is a central route or control area. Site is where the Spike can be planted.

Default

“Default” usually refers to a common plant or setup location; exact positions vary by map.

Choke

A constrained route where utility and crossfires can be concentrated.

MAP STUDY LOOP

  1. Study the actual layout image.
  2. Learn the callouts and major lanes.
  3. Identify defender rotations.
  4. Learn map-specific mechanics.
  5. Then grind lineups and set plays.
