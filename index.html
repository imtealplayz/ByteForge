REFERENCE / BATTLEFIELDS

Maps

Maps are systems, not pictures. Learn how paths, sightlines, sites, chokepoints, rotations, and unique mechanics change decisions.

MAP VOCABULARY

Main / Link / Mid / Site

Main usually means a primary lane into or toward a site. Link connects areas. Mid is a central route or control area. Site is where the Spike can be planted.

Default

“Default” usually refers to a very common plant or setup location, not a universal rule that every map uses exactly the same spot.

Choke

A narrow route where utility and crossfires are easier to concentrate. Winning a choke can be more valuable than taking random space elsewhere.

MAP STUDY LOOP

  1. Learn the callouts and major lanes.
  2. Identify the safest defender rotations.
  3. Find attack-side choke points.
  4. Learn which walls / doors / movement mechanics matter.
  5. Only then grind lineups and set plays.

TRAINING DRILLS

10-minute mechanical loop

  1. 2 min: move-stop-shoot bots.
  2. 2 min: only head-level crosshair placement.
  3. 2 min: burst/tap discipline at different ranges.
  4. 2 min: strafe → stop → one clean fight.
  5. 2 min: Deathmatch focused on positioning, not score.

The goal is to train one variable at a time instead of mindlessly queueing.
