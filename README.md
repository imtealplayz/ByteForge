# VALORANT Wiki — ByteForge

ByteForge is now a **VALORANT learning and reference wiki**. The repository name stays `ByteForge`, but the website itself is a fresh VALORANT project.

## What is included

- Current Agent index with all agents tracked in this build, searchable and filterable by role
- Agent role explanations and study notes
- Weapon index covering pistols, SMGs, shotguns, rifles, snipers, and heavy weapons
- Map index with map structure, signature mechanics, and study concepts
- Gameplay encyclopedia covering:
  - Round structure
  - Economy and buying
  - Crosshair placement
  - Movement accuracy
  - Peeking
  - Trading
  - Utility
  - Smokes and flashes
  - Information
  - Defaults and executes
  - Post-plant and retakes
  - Clutching
  - Sound
  - Space control
  - Numbers advantage
  - Anti-eco awareness
  - Mental reset
- Active-recall quiz room
- Mechanical training drill
- Search/filter UI
- Mobile responsive layout
- Links to Riot's official sources for live updates

## Current-state note

The site was built against the live VALORANT information available on **September 10, 2026**. Riot's official site lists **Season 26, Act V** as live and its latest game-update entry as **Patch 13.05** from September 1, 2026.

Patch data, agent balance, maps in rotation, weapon values, and other gameplay details can change. The wiki deliberately treats Riot's current pages and patch notes as the authoritative source for live values.

## Run locally

There is no build step.

```text
Open index.html
```

Or serve the folder with any static HTTP server.

## Deploy to Vercel

Import `imtealplayz/ByteForge` into Vercel. It is a static HTML/CSS/JavaScript project and needs no build command or environment variables.
