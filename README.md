# ByteForge ⚡

**ByteForge** is an interactive learning site for understanding **8-bit binary** and **hexadecimal**.

## Features

- 📚 Binary and hexadecimal lessons
- 🔢 8-bit place-value visualization (`128 → 1`)
- 🧩 Interactive binary bit switches
- 🎯 Decimal → Binary practice
- 🔄 Binary → Decimal practice
- 🔷 Hexadecimal `0–F` / nibble mapping
- 🎯 Hex → 8-bit Binary practice
- 📊 Accuracy and streak tracking
- 💾 Progress saved locally with `localStorage`
- 📱 Responsive dark interface
- ⚡ No backend or environment variables required

## Tech stack

- HTML
- CSS
- Vanilla JavaScript
- `localStorage`

## Run locally

No build step is required. Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Deploy to Vercel

Import this repository into Vercel. Use the default settings — there is no build command or output directory.
